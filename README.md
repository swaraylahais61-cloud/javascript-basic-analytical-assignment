# JavaScript Basic Analytical Assignment

This is a simple JavaScript assignment project.

## What is in this repo?

- `src/purchaseCalculator.js` - calculates shopping total with discount and shipping
- `src/scholarshipEligibility.js` - checks scholarship eligibility
- `screenshots/` - screenshots of the program output
- `case1.js` - archived reference

## How to run

From the project folder, run:

```bash
node src/purchaseCalculator.js
node src/scholarshipEligibility.js
```

## Notes

This assignment focuses on basic JavaScript logic such as:
- variables
- arithmetic operations
- conditions
- console output

The goal is to practice simple analytical coding in a clean and easy-to-read structure.
